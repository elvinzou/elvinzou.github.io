# UpYouGo product website

Static bilingual site prepared for product and merchant-domain review. The invitation beta has no live checkout. `index.html`, `privacy.html`, `terms.html` and `refunds.html` are the English pages; `*-zh.html` are Simplified Chinese versions. The image is a real extension screenshot. All links are relative so the site can be hosted from a project path such as GitHub Pages.

Before activating payment, update the site with the approved merchant of record, final checkout terms, refund mechanism, the actual purchase/recovery instructions and the privacy details for payment/identity data. Submit the exact checkout-origin domain in the payment provider dashboard. A working site and sandbox transaction do not prove seller or payout approval.
